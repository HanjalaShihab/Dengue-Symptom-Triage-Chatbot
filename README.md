# 🤖 Dengue Symptom Triage Chatbot with Machine Learning

A bilingual (English/Bangla) Telegram chatbot for dengue symptom assessment using both rule-based logic and machine learning predictions.

## 🎯 Features

### 🤖 Chatbot Features
- **Bilingual Interface**: English and Bengali support
- **Hybrid Prediction**: ML predictions with rule-based fallback
- **Personalized Datasets**: Individual CSV files for each user
- **Detailed Analysis**: Symptom breakdown with medical logic
- **Research Ready**: Complete data collection pipeline

### 🧠 Machine Learning
- **Random Forest Model**: Trained on 2000+ synthetic cases
- **Confidence Scoring**: ML predictions with confidence levels
- **Feature Importance**: Identifies most predictive symptoms
- **Continuous Learning**: Can be retrained with new data

### 📊 Research Capabilities
- **Synthetic Data Generator**: 2000 realistic dengue cases
- **Comprehensive Analysis**: ML vs rule-based comparison
- **Visualizations**: Confusion matrices, feature importance
- **Research Report**: Auto-generated paper-ready analysis
